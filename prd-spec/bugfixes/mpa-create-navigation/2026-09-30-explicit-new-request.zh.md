## 证据、目标与范围

目录打开 `MpaCreateDialog` 后恢复该地域的浏览器草稿，已提交草稿锁定配置。
`startAnotherAgent` 已能重置身份、默认值、密钥和状态，但守卫及按钮仅允许
失败/取消任务。POST 结果未知或任务查询失败时，用户无法开启可编辑的新请求。
用户已明确批准“新建智能体”生成新请求。

FR-1：任何已提交草稿都提供显式“新建智能体”，包括未知、运行中和取消中的任务。
UI 操作未结束或配置加载时禁用。仅重开窗口或切换步骤不改变身份。
FR-2：复用现有重置：新请求/智能体 ID、第一步、开放输入、配置的镜像/PG 默认值，
清空描述、OpenViking/TOS 密钥及任务状态。点击新建前，同 ID 重试保持不变。
FR-3：说明新建不会取消旧任务。仅替换浏览器恢复记录；明确提交前不发起
POST、取消或云端变更。旧任务未结束时，现有单用户任务限制可能拒绝新提交。
通过已有 task-ID effect 中止旧轮询并忽略迟到响应。

不改 API、Runtime/Worker、创建服务、任务持久化和凭据契约。不增加任务历史 UI
或自动云资源清理。生成的智能体 ID 仍只读。复用 Button/ModalLayout，不改 CSS
或增加依赖。
