# 创建失败后新建另一个 MPA 智能体

[English](2026-09-24-start-another-agent-after-failure.md)

- Change ID: `studio-mpa-new-after-failure`
- Date: 2026-09-24
- Status: 用户要求在失败后创建不同的智能体，已批准该范围
- Component: [Studio MPA 创建](../../../specs/studio-mpa-creation/README.zh.md)

## 背景与证据

创建弹窗将已提交的 `requestId`、`agentId` 和 `taskId` 保存在 `sessionStorage`，重新打开时恢复；只有成功后才清除。任务失败或取消后，关闭再点击创建卡片仍会回到旧任务，界面仅提供重试。生成的智能体 ID 只读，用户无法在界面中开始创建另一个智能体。

## 目标、非目标与场景

在**已确认失败或取消**后，提供明确的新建其他 MPA 智能体方式。保留原 ID 重试以及服务端任务和资源记录。不重置运行中任务或结果不明的 POST，不删除云资源，不修改任务 API，也不持久化 OpenViking 凭据。

- 失败或取消的任务同时显示重试和独立的新建操作。
- 选择新建后，仅清除浏览器恢复记录，生成新的请求 ID 和智能体 ID，三步表单回到基础信息，并恢复服务端的镜像及 PG 字段默认值。
- 关闭并重新打开新草稿时仍使用新的身份，不再次提交旧任务。
- 运行中、取消中及提交结果不明时不提供该操作。

## 需求与设计

- **FR-1：**仅在任务快照明确为 `failed` 或 `cancelled` 时展示本地化的新建操作，同时保留现有重试路径。
- **FR-2：**点击后替换旧会话记录并清除内存中的任务身份；生成新的 UUID 和符合现有长度的 `mi-` ID，重置描述、OpenViking 输入及向导步骤，并使用当前安全配置预填镜像和手动 PG 目标。
- **FR-3：**不改动服务端任务及已登记云资源。等待中或结果未知的请求仍保持原身份，以便幂等恢复。OpenViking API Key 不进入浏览器存储。

涉及文件：创建弹窗、双语界面文本、弹窗测试、Studio 组件契约和前端用户文档。无需修改后端或云接口。

## 任务、测试与风险

1. 先加失败回归测试，覆盖重新打开失败任务后新建、ID 更新、密钥清空及新草稿持久化；覆盖取消态和运行态不展示新建。
2. 使用现有按钮与表单状态实现终态操作，保持重试语义。
3. 运行定向前端测试、全部前端测试/构建/产物检查；环境允许时做真实浏览器交互检查。

误触重置可能放弃可恢复任务，因此操作仅在确认终态时提供，且旧任务与资源仍保留在服务端。验收要求存在清晰的新建入口、不同的请求及智能体 ID、重置后不显示旧任务状态，并保持同 ID 重试。

## 审查与验证

设计审查：仅在确认任务终态后重置，不破坏服务端幂等边界。显式操作让放弃旧恢复草稿成为用户主动选择；不暗示清理或删除。复用现有会话键和组件按钮。已核对中英文契约与说明的行为一致。
