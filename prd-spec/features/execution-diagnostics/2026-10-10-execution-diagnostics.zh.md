## 依据与范围
现有 Codex call_llm Span 覆盖整个执行；Responses Shim 使用非流式 litellm.aresponses。Worker HTTP 请求已有记录，SSE 订阅尚未记录。本设计记录性能诊断 goal 已授权的范围，不宣称新增用户审批或已部署能力。

## 要求与设计
FR-1：保留整轮兼容记录，单独记录各次模型后端请求并关联原 Agent；不重复记录整轮用量，不计算合成 TTFT。
FR-2：记录 Worker 请求与每次 SSE 连接，仅传递 W3C 链路上下文；认证、幂等、重试上限、事件校验和游标保持原行为。
FR-3：流 Span 不得在异步生成器 yield 期间保持为当前 Span；完成、失败、取消和关闭生成器时结束。不记录 Endpoint、路由标识、正文和原始异常。
FR-4：缺少可选观测依赖时保持执行；复用既有 Provider 和导出器。

## 任务与验收
T-1 / AC-1：模型测试证明父子关联、重试、失败与取消，Codex 索引兼容。
T-2 / AC-2：Worker HTTP 测试证明 W3C 传递、脱敏与 Key 不变。
T-3 / AC-3：SSE 测试证明各次连接父子关系、游标连续、取消与关闭，以及当前上下文不泄漏。
T-4 / AC-4：同步双语契约及使用文档，运行受影响测试和 pre-commit，记录实际结果。

## 评审与风险
直接评审：不改公开签名、协议、认证、持久化、并发职责或部署配置。重试遵循现有语义。异步生成器上下文泄漏是必须解决的问题，使用不设为当前上下文的流 Span。客户端订阅时间不是远端排队、启动或执行耗时。Worker 接收端传递、APMPlus 接收与部署版本尚未验证。SSE 实现及验收待完成，已有 HTTP / 模型测试证据见 PR #1161。本记录补齐已有改动依据，并先于 SSE 扩展建立。

验证（2026-10-10）：10 项 Worker 链路测试通过，17 项现有远端 Sandbox 测试通过（新增用例前的初次合并运行共 22 项通过）。覆盖 SSE 完成、重连游标、提前关闭、取消和 HTTP 失败。全仓回归、真实 Codex smoke 和 APMPlus 接收为 not_run：缺少隔离的完整 smoke 依赖与部署接收证据。流程偏差：SSE 测试在首次实现编辑后添加，没有先执行失败测试；现已补充直接行为断言。不宣称已部署能力。
