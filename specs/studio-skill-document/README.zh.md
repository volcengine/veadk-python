# Studio 技能正文编辑

[English](README.md) · [设计](../../prd-spec/features/mpa-agent-info-rail/2026-09-18-mpa-agent-info-rail.zh.md)

## 职责与接口

复用技能管理身份解析器和版本仓库负责鉴权与发布。MPA 侧栏传入准确的地域/空间/技能 ID；编辑器不选择其他空间、不改变 Runtime 绑定。

GET `/web/skill-management/spaces/{space_id}/skills/{skill_id}/document?region=...` 返回最新可见版本的 `{content, baseVersion, canUpdate}`。同路径 PUT 接收 `{content, baseVersion}`，复用版本上传行为，在所选空间创建并发布原生新版本。content 最多 262144 字符，baseVersion 最多 64 字符，均不可为空。服务端检查归属。共享与审核空间即使管理员也保持只读；其他个人空间沿用所有者/管理员权限。

## 完整性与并发

仅替换已校验归档根目录或单层包装目录中的 SKILL.md，保留其他成员、二进制字节及属性。沿用 ZIP 限制与 frontmatter 校验；改变技能名称返回 422。编辑器展示转义纯文本，不执行文档中的标记。

保存前在读取原归档之前和既有进程内上传锁中分别检查 baseVersion。版本过期时在云写入前返回 `SKILL_DOCUMENT_CONFLICT`（409）。提供方没有原子比较交换，外部写入仍可能在校验后发生竞态；这不是分布式锁。保存失败/结果待定不代表回滚，应保留编辑并提示重试前核对当前版本。

## 界面生命周期

明确支持加载/错误/重试、只读、未保存修改确认、兼容 IME 的 Escape、焦点圈定与恢复，以及保存中禁用控件。阻止重复保存。卸载取消浏览器请求并忽略迟到响应，但无法回滚服务端已接受的发布。保存后刷新绑定列表；Runtime 执行新版本可能需要缓存刷新或新会话。本地验证不会自动修改真实服务。

## 验证

后端测试覆盖身份、读写权限、名称保留、二进制/权限位保留及版本冲突。组件测试覆盖只读、读取重试、保存失败保留草稿、重复保存、卸载取消、Escape/IME。日期结果和浏览器限制见双语设计。
