# Hello World Example

The simplest possible VeADK example that demonstrates the basic structure of a VeADK application.

## What it does

- Creates a simple agent that responds with "Hello World!"
- Uses the `Runner` to execute the agent
- Prints the response to the console

## How to run

1. Make sure you have VeADK installed and configured properly
2. Run the example:

```bash
python main.py
```

You should see "Hello World!" printed in the console.
